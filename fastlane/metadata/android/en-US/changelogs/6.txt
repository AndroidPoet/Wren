Downloads: in Tor mode, downloads now run inside Wren through Tor with their own notification, pause, resume and cancel, instead of being refused; a finished download offers to open from a snackbar; data: links save under the name the page gave them; names the server states are kept as they are.
Privacy: HTTPS-only mode (refuses plain HTTP pages outright, blocks mixed content); fingerprint noise is now the same for a site across visits in a session, and different for the same tracker on different sites; bounce redirectors (google.com/url, Facebook, Outlook safelinks) and AMP cache links are unwrapped before the first request; Attribution Reporting is turned off; the EasyList Cookie list is on by default; more consent platforms are declined; remote suggestions stay off in private tabs; the stored clear-on-exit wipe finishes on the next start if the app was killed first.
Security: a frame can no longer steer the tab by being rewritten as the document; links to other apps open only from a tap, never from a frame or a redirect, and show a message when no app can open them; HTTP authentication prompts are supported; the app lock stays closed when the device's authenticator is temporarily unavailable; the HTTPS upgrade and link cleaning apply to the page's own navigations; popup transport views are released.
Blocking: an important rule beats an exception even without a host-set hit; $badfilter cancels host-set entries; the allowlist exempts a site from cosmetic hiding too.
