# Security

Wren is a privacy tool, so a leak is a security bug: a tracker request that gets past the
blocker, a private tab writing to disk, traffic leaving Tor, or data surviving "Clear
everything".

Report these privately through GitHub: open the repository's **Security** tab and choose
**Report a vulnerability**. Please don't open a public issue for them. Include the Wren
version, Android version and device, and the steps or page that show the problem.

Only the latest release gets fixes.
